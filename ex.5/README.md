# Exercício 5 — Secretaria acadêmica

Entrega de arquitetura adaptada ao trabalho do grupo, conforme o enunciado **“A arquitetura do agente do seu trabalho”**.

## Documento para entrega

Leia [docs/arquitetura-v1.md](docs/arquitetura-v1.md). O documento contém as três camadas, o fluxo de sete etapas, contratos de entrada e saída, ferramentas, escritas, estado, orçamentos, exemplos de retorno e justificativas dos padrões.

Também foi salvo em [../docs/arquitetura-v1.md](../docs/arquitetura-v1.md), no caminho exigido pelo professor no repositório do trabalho. Esta pasta contém uma cópia idêntica para organizar o exercício. Ao revisar a entrega, sincronize ambas.

## Material de apoio

- [Case da Parte 1](docs/case.md): cópia de referência; a revisão arquitetural está na v1, que distingue proposta de implementação existente.
- [Enunciado do trabalho](enunciados/exercicio_05-trabalho.md): orientação original recebida.
- [Enunciado do laboratório](enunciados/exercicio_05-laboratorio.md): atividade prática de despesas, em outro domínio, preservada para consulta. Referências relativas dentro dos enunciados apontam para o material da disciplina, não incluído nesta pasta.

O laboratório solicita `08-analista.py` no repositório do laboratório e é uma entrega distinta. Esta pasta entrega a arquitetura do case da secretaria; não contém uma implementação do analista de despesas. O enunciado do trabalho permite entregar a arquitetura sem escrever código.

Não é necessário executar o projeto nem configurar chave de API para ler ou entregar esta arquitetura. As proporções são estimativas e os exemplos são ilustrativos, identificados no documento; não foram apresentados como execuções reais.
