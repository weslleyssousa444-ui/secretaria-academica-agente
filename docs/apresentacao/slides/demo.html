23 / 29

Para a demonstração, publicamos o agente na internet. O navegador abre uma página de chat na Hostinger, que guarda o histórico das conversas no próprio navegador. A página fala com um pequeno repasse em PHP, no mesmo servidor, que só deixa passar o chat e a verificação de saúde. O repasse chama a API do agente, que roda no Render a partir do mesmo Dockerfile do repositório, e a API chama o modelo na Groq. Roteiro sugerido: pedir uma declaração com o RA 20231045; pedir a segunda via com o RA 20230198, que tem mensalidade em aberto, e mostrar que o agente não emite; pedir trancamento com o RA 20229012 e mostrar o caso aguardando a coordenação; e fazer uma dúvida do Regimento para mostrar o artigo citado. Cuidados: os dados são fictícios; a chave da Groq fica só nas variáveis do servidor; as rotas da coordenação não são expostas pelo site; e, no plano gratuito, o servidor dorme sem uso, então a primeira resposta pode levar até um minuto. Abrir o site alguns minutos antes. [Confirmar o endereço do site e testar o roteiro no dia.]
